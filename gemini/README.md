# Gemini API tests

Since the Gemini API has a free tier, it's being used here in some tests.

Here we use ```gemini-2.0-flash```.

The ```gemini-2.5-pro-exp-03-25``` model will be tested in the future, since the API pricing page shows this version is free of charge.

## Usage

```
pip install haystack-ai google-ai-haystack
python example_haystack.py
```
